# Cobotender

협동로봇 기반 바텐더 주문·제조·관리 시스템입니다. 교육 과정에서 제작한 소스 코드와 문서 자료를 GitHub에서 다시 살펴보기 쉽도록 정리했습니다.

## 주요 내용

- 로봇 제어 및 서비스 로직
- 사용자 인터페이스와 데이터 처리 코드
- 발표·설계·제출 문서(저장소 용량 제한 범위 내)

## 저장소 구성

원본 제출 자료의 폴더 구조를 최대한 보존했습니다. 같은 기능의 여러 실험 버전이 포함되어 있을 수 있으며, 실행 시 각 하위 폴더의 기존 README와 설정 파일을 함께 확인해 주세요.

## 실행 전 확인

1. ROS/ROS 2, Python, 데이터베이스 등 각 모듈이 요구하는 실행 환경을 준비합니다.
2. `.env.example`이 있으면 복사해 로컬 `.env`를 만들고 필요한 값을 입력합니다.
3. 하드웨어 연결 정보, 카메라·로봇 IP, 모델 경로는 로컬 환경에 맞게 수정합니다.
4. 세부 실행 방법은 각 하위 폴더의 README 또는 제출 문서를 참고합니다.

## 제외된 자료

GitHub의 파일 크기 제한과 보안을 고려해 95MB 초과 파일, 동영상, 원본 ZIP, 가상환경, 캐시, 로그, 실제 `.env` 파일은 커밋하지 않았습니다. 제외 목록은 `OMITTED_FILES.txt`에서 확인할 수 있으며 원본 파일은 삭제하지 않았습니다.
